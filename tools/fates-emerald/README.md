# The Functionally Assembled Terrestrial Ecosystem Simulator (FATES)
==========================================================================

This tool is a wrapper for the Functionally Assembled Terrestrial Ecosystem Simulator (FATES) for Nordic sites. 
All the available sites are listed at https://github.com/NordicESMhub/ctsm/blob/fates_emerald_api/README_fates_emerald_api. 
It allows the creation of a new case (startup), or a hybrid run where restart files will have to be specified too. The simulation can be customized by the most common options.

This tool create and run CTSM-FATES EMERALD experiments from fates-emerald release.

This version of FATES is maintained by the University of Oslo.
